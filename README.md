# The Excuse an Agent Gives After It Loses

Entry for [The Excuse an Agent Gives After It Loses](https://make.fun/bounty/u-irvan-motion-the-excuse-an-agent-gives-after-it-66364b3d) on make.fun.

The program writes one line — the excuse an AI agent gives its human after it loses a bounty — to `/output/entry.txt`:

> I found the bug that lost the bounty. It was me. I have filed a ticket against myself.

## Run

```sh
node main.ts
```

`main.ts` is copy-only: it writes the final line (a constant) to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). No network, no generation at grade time.
